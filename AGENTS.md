# Email Studio

@brand/voice.md

This studio is for planning and writing email campaigns for a small business. It holds the brand context, lead lists, campaign drafts, and working notes so an agent can help research, plan, and write emails.

## Folders

- `brand/` — Brand voice, positioning, product details, and other background an agent should read before writing.
- `leads/` — Lead lists and audience segments, including the context needed to personalize emails.
- `campaigns/` — Campaign plans, sequences, drafts, and final copy.
- `notes/` — Research, decisions, ideas, and other working notes.

## Rules

- Write in plain English.
- Never send email to real people.
- Ask me before deleting anything.
