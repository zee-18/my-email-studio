# Skills I Chose

## Use these

1. **coreyhaines31/marketingskills** (skills: `emails`, `email-sequence`, `copywriting`, `cold-email`) — published by Corey Haines, a marketer and founder who open-sources his marketing playbooks. The GitHub repo has about **59,000 stars**, recent commits, and the `emails` skill passes all three security audits (Agent Trust Hub, Socket, Snyk). This is the best source for writing campaigns, lifecycle emails, and sequences.

2. **resend/resend-skills** (plus `resend/email-best-practices` and `resend/react-email`) — published by **Resend**, an email API company, so this is first-party. `resend-skills` has about **211 stars**, `email-best-practices` about **147**, and `react-email` about **19,900**. This is the best source for actually sending email: official API usage, deliverability and compliance guidance, and React email templates.

Note: `anthropics/skills` is an official publisher with about **188,000 stars**, but none of these searches surfaced an email or campaign skill from it, so I did not force it into the list.

## Avoid these

1. **open.feishu.cn/lark-mail** — it shows about **865,000 installs**, but it is a Feishu/Lark mailbox administration tool that requires `lark-cli` and a Lark account, with mostly Chinese documentation. It is not a campaign writer or a marketing email platform, and its source is a website rather than a GitHub repository, so there are no repo stars or audits to verify. Wrong tool and vendor lock-in.

2. **mbfinotti/advertising-skills** — only **2 GitHub stars** and a publisher with no track record. Its content is about paid-ad budget pacing, not email marketing, and the 26,000 installs do not make up for the lack of reputation or fit.

## How I decided

Before installing any skill, I would check these three things:

1. **Publisher identity** — is it an official company (like Resend or Anthropic), a known person with a real profile, or an unknown account? First-party and named authors are safer.
2. **Repository health** — GitHub stars, recent commits, and security audit results. I do not use install counts alone, because they are easy to inflate and do not prove quality.
3. **Actual fit and contents** — read the `SKILL.md` and its references to confirm it really does campaign writing or email sending, and check for required CLIs, permissions, and prompt-injection warnings before installing.
